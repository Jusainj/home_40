## Hardware Connections
DHT11 Pinout:
VCC → 3.3V or 5V (Raspberry Pi Pin 1 or Pin 2)

GND → Ground (Raspberry Pi Pin 6)

SIG → GPIO 4 (Raspberry Pi Pin 7)
(or any other GPIO pin if you prefer, but update the script accordingly)

## GPIO Pin Usage:
GPIO 4 (Pin 7) is typically used for data (SIG) on the Raspberry Pi.

Ensure the DHT11 sensor is powered correctly, either using 3.3V or 5V (check sensor specs).
